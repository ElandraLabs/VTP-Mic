# Security

VTP-Mic carries your voice, so security reports are welcome and taken seriously.

**Please do not open a public issue for a vulnerability.** Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository. Include the version (`mic-vX.Y.Z`), what you did, and what
happened. We aim to answer within a few days and will tell you when a fixed version is released.

Every release is signed with the same key; its SHA-256 fingerprint is in [docs/PRIVACY.md](docs/PRIVACY.md).
